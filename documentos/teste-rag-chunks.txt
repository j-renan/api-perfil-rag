Python é uma linguagem de programação de alto nível, conhecida por sua sintaxe simples e legibilidade. Ela é utilizada no desenvolvimento de aplicações web, automação de processos, análise de dados, inteligência artificial e aprendizado de máquina.
O Flask é um microframework web desenvolvido em Python. Ele permite construir aplicações web e APIs REST de maneira simples e flexível. Sua arquitetura permite adicionar extensões conforme as necessidades do projeto, incluindo autenticação, validação de dados e integração com bancos de dados.
O PostgreSQL é um sistema gerenciador de banco de dados relacional e objeto-relacional. Ele oferece suporte a consultas SQL, transações, integridade referencial e diversos tipos de dados. Também pode ser estendido com funcionalidades adicionais, como a extensão pgvector, utilizada para armazenar e consultar vetores.
O RAG, ou Retrieval-Augmented Generation, é uma técnica que combina recuperação de informações com modelos de linguagem. Primeiro, os documentos são divididos em pequenos trechos chamados chunks. Em seguida, cada trecho é convertido em um vetor numérico chamado embedding.
Os embeddings representam semanticamente o conteúdo dos textos. Isso permite comparar uma pergunta com os documentos armazenados e recuperar os trechos mais relevantes. A similaridade entre vetores pode ser calculada utilizando diferentes métricas, como distância cosseno.
Uma aplicação RAG pode utilizar Flask para disponibilizar uma API, PostgreSQL com pgvector para armazenar os embeddings e Sentence Transformers para transformar textos em representações vetoriais. Essa arquitetura permite desenvolver sistemas de perguntas e respostas baseados em documentos próprios.
A divisão adequada dos documentos em chunks é importante para a qualidade da recuperação semântica. Trechos muito pequenos podem perder contexto, enquanto trechos muito grandes podem reunir assuntos diferentes. O overlap ajuda a preservar informações nas fronteiras entre os chunks.
